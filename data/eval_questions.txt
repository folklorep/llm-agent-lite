# 两个检索器的差距被压缩到看不见（都是 85%）。

# v2 扩到 50 题，并把改写题比例从 1/2 提到 2/3：

#
# ============================================================================
# 标注规则（三条，都踩过坑）
# ============================================================================
# 1. 关键词必须**逐字出现在语料里**
#    （v2 初稿有 2 题的关键词根本不在语料里，是脚本查出来的）
# 2. 关键词必须是**有辨识度的短语**，不能是单字或高频词
#    （初稿里「0」出现在 27 个块里、「return」出现在 9 个块里 ——
#      这种关键词等于没标注，命中哪个块都算对）
# 3. 改写题要真的换说法，不能只调换语序
